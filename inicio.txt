# GUÍA DE INICIO - PROYECTO CLÍNICA LARAVEL
# ==========================================

## 📁 ARCHIVOS DE DOCUMENTACIÓN

### **1. `comandos_docker_laravel.txt`**
**Para qué sirve:** Comandos diarios y mantenimiento
- Comandos Docker esenciales (start, stop, logs, etc.)
- Gestión de contenedores y servicios
- Backup y restauración de base de datos
- Comandos de emergencia y troubleshooting
- Referencia rápida para uso cotidiano

### **2. `instalacion_limpia_ip.txt`**
**Para qué sirve:** Instalación inicial en servidor nuevo
- Instalación completa de Docker en Ubuntu 22.04
- Configuración de firewall y seguridad básica
- Setup del proyecto Laravel desde cero
- Configuración para funcionar solo con IP del servidor
- Resultado: `http://123.45.67.89`

### **3. `migracion_a_dominio_ssl.txt`**
**Para qué sirve:** Agregar dominio y SSL a aplicación existente
- Migración sin downtime desde IP a dominio
- Configuración de Nginx reverse proxy
- Instalación de certificados SSL Let's Encrypt
- Procedimientos de rollback si algo falla
- Resultado: `http://IP` → `https://midominio.com`

## 🔧 ARCHIVOS DE CONFIGURACIÓN DOCKER

### **4. `docker-compose.yml`**
**Para qué sirve:** Orquestación de contenedores
- Define servicios: nginx, php-fpm, mysql
- Configuración de puertos y volumes
- Variables de entorno
- Red interna entre contenedores

### **5. `docker/php/Dockerfile`**
**Para qué sirve:** Imagen PHP personalizada
- PHP 8.3 Alpine con extensiones Laravel
- Composer preinstalado
- Configuración de permisos
- Optimizaciones para producción

### **6. `docker/php/entrypoint.sh`**
**Para qué sirve:** Inicialización automática del contenedor PHP
- Espera a que MySQL esté listo
- Ejecuta migraciones automáticamente
- Configura permisos de Laravel
- Optimiza para producción

### **7. `docker/nginx/nginx.conf`**
**Para qué sirve:** Configuración principal de Nginx
- Optimizaciones para Laravel
- Configuración de PHP-FPM
- Headers de seguridad
- Compresión gzip

## ⚡ SCRIPTS DE AUTOMATIZACIÓN (Archivos .sh)

### **ORDEN DE EJECUCIÓN:**

#### **PASO 1: Servidor Nuevo - Instalación Inicial**
```bash
# 1. Ejecutar instalación automática
chmod +x instalacion_automatica_ip.sh
sudo ./instalacion_automatica_ip.sh
```
**Archivo:** `instalacion_automatica_ip.sh`
**Para qué sirve:**
- Instala Docker y dependencias
- Configura firewall
- Clona y configura el proyecto
- Requiere reinicio del servidor

#### **PASO 2: Después del Reinicio**
```bash
# 2. Completar instalación después del reinicio
chmod +x post_reboot_setup.sh
./post_reboot_setup.sh
```
**Archivo:** `post_reboot_setup.sh`
**Para qué sirve:**
- Completa la configuración después del reinicio
- Levanta contenedores Docker
- Verifica que todo funcione correctamente
- Resultado: Aplicación funcionando con IP

#### **PASO 3: Configuración Rápida (Alternativa)**
```bash
# 3. Setup rápido si ya tienes Docker instalado
chmod +x quick_setup_production.sh
./quick_setup_production.sh
```
**Archivo:** `quick_setup_production.sh`
**Para qué sirve:**
- Setup rápido para producción
- Asume que Docker ya está instalado
- Configura Laravel y base de datos
- Alternativa más rápida si ya tienes el servidor preparado

#### **PASO 4: Agregar SSL (Opcional)**
```bash
# 4. Solo cuando ya funcione con IP y tengas dominio
chmod +x setup_ssl.sh
sudo ./setup_ssl.sh
```
**Archivo:** `setup_ssl.sh`
**Para qué sirve:**
- Agrega dominio y certificados SSL
- Configura Nginx reverse proxy
- Migra de HTTP a HTTPS
- Ejecutar SOLO después de que funcione con IP

## 🎯 FLUJO RECOMENDADO

### **Para Servidor Nuevo (Recomendado):**
1. `instalacion_automatica_ip.sh` → Reiniciar servidor
2. `post_reboot_setup.sh` → Verificar funcionamiento con IP
3. `setup_ssl.sh` → Solo si tienes dominio

### **Para Servidor con Docker Existente:**
1. `quick_setup_production.sh` → Verificar funcionamiento con IP
2. `setup_ssl.sh` → Solo si tienes dominio

### **Para Uso Diario:**
- Consultar `comandos_docker_laravel.txt`
- Usar comandos Docker básicos
- Hacer backups regulares

## 📝 NOTAS IMPORTANTES

- ✅ **Siempre verificar** que funcione con IP antes de agregar SSL
- ✅ **Hacer backup** antes de cambios importantes
- ✅ **Seguir el orden** de los scripts
- ❌ **No ejecutar** `setup_ssl.sh` si no tienes dominio configurado
- ❌ **No saltarse** el paso de verificación con IP

## 🆘 EN CASO DE PROBLEMAS

1. Revisar `comandos_docker_laravel.txt` para troubleshooting
2. Verificar logs: `docker-compose logs -f`
3. Reiniciar servicios: `docker-compose restart`
4. Si falla SSL: usar procedimiento de rollback en `migracion_a_dominio_ssl.txt`
