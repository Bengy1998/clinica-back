# INSTALACIÓN LIMPIA - SOLO IP DEL VPS
# ===================================

## 🎯 OBJETIVO: Aplicación funcionando con IP del servidor
## Ejemplo: http://123.45.67.89

## 📋 REQUISITOS
# - VPS Ubuntu 22.04
# - Acceso root o sudo
# - IP pública del servidor

## 🚀 INSTALACIÓN PASO A PASO

### PASO 1: ACTUALIZAR SISTEMA
```bash
sudo apt update && sudo apt upgrade -y
sudo reboot
```

### PASO 2: INSTALAR DOCKER
```bash
# Instalar dependencias
sudo apt install apt-transport-https ca-certificates curl gnupg lsb-release -y

# Agregar repositorio Docker
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# Instalar Docker
sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io docker-compose-plugin -y

# Instalar Docker Compose standalone
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# Configurar usuario
sudo usermod -aG docker $USER
```

### PASO 3: CONFIGURAR FIREWALL BÁSICO
```bash
sudo apt install ufw -y
sudo ufw enable
sudo ufw allow 22/tcp          # SSH
sudo ufw allow 80/tcp          # HTTP
sudo ufw allow 3306/tcp        # MySQL (opcional)
sudo ufw status
```

### PASO 4: REINICIAR Y VERIFICAR
```bash
sudo reboot

# Después del reinicio, verificar Docker
docker --version
docker-compose --version
```

### PASO 5: CLONAR PROYECTO
```bash
# Navegar al directorio web
cd /var/www

# Clonar proyecto (ajustar URL)
sudo git clone https://github.com/tu-usuario/clinica-back.git clinica
sudo chown -R $USER:$USER clinica
cd clinica
```

### PASO 6: CONFIGURAR VARIABLES DE ENTORNO
```bash
# Copiar archivo de ejemplo
cp .env.example .env

# Editar variables básicas
nano .env
```

**Contenido .env básico:**
```env
APP_NAME="Clínica"
APP_ENV=production
APP_KEY=
APP_DEBUG=false
APP_URL=http://TU_IP_AQUI

LOG_CHANNEL=stack
LOG_LEVEL=error

DB_CONNECTION=mysql
DB_HOST=mysql
DB_PORT=3306
DB_DATABASE=clinica
DB_USERNAME=root
DB_PASSWORD=root2025

CACHE_DRIVER=file
FILESYSTEM_DISK=local
QUEUE_CONNECTION=sync
SESSION_DRIVER=file
SESSION_LIFETIME=120
```

### PASO 7: INICIAR APLICACIÓN
```bash
# Construir e iniciar contenedores
docker-compose up -d --build

# Esperar que MySQL esté listo (30 segundos)
sleep 30

# Generar clave de aplicación
docker-compose exec php php artisan key:generate --force

# Ejecutar migraciones
docker-compose exec php php artisan migrate --force

# Crear enlace de storage
docker-compose exec php php artisan storage:link

# Optimizar para producción
docker-compose exec php composer install --optimize-autoloader --no-dev
docker-compose exec php php artisan config:cache
docker-compose exec php php artisan route:cache
docker-compose exec php php artisan view:cache
```

### PASO 8: VERIFICAR FUNCIONAMIENTO
```bash
# Ver estado de contenedores
docker-compose ps

# Ver logs si hay problemas
docker-compose logs

# Test desde el servidor
curl -I http://localhost

# Obtener IP pública
curl -4 icanhazip.com
```

## 🔧 COMANDOS DE MANTENIMIENTO BÁSICO

### Ver estado general:
```bash

sudo systemctl status docker
```

### Backup básico:
```bash

docker-compose exec mysql mysqldump -u root -proot2025 clinica > backup_$(date +%Y%m%d).sql

gzip backup_$(date +%Y%m%d).sql
```

### Actualización de código:
```bash

git pull origin main

# Reiniciar contenedores
docker-compose down
docker-compose up -d --build

# Limpiar caché
docker-compose exec php php artisan optimize:clear
```

## 🆘 TROUBLESHOOTING BÁSICO

### La aplicación no carga:
```bash
# Verificar contenedores
docker-compose ps

# Ver logs de errores
docker-compose logs nginx
docker-compose logs php

# Reiniciar todo
docker-compose restart
```

### Error de permisos:
```bash
# Dentro del contenedor PHP
docker-compose exec php chmod -R 755 /var/www/html
docker-compose exec php chmod -R 775 storage bootstrap/cache
```

### Sin espacio en disco:
```bash
# Ver espacio
df -h

# Limpiar Docker
docker system prune -f

# Limpiar logs del sistema
sudo journalctl --vacuum-time=7d
```
